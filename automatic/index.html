План отдела

ОП на месяц: текущие, новые, Р1 без двойного счёта. Рынок — риск, не вычет.

Считает ~30–40 сек: 1С + склад + цены конкурентов + воронка 1С РТЛ. Excel сразу попадает во вкладку «Готовые».

Берётся срез из сервиса цен конкурентов. Рынок в плане считается только по этой дате.

По умолчанию — следующий месяц после последней сделки в загруженных 1С.
